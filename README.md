# Meso

The layer between your Mac and everything plugged into it: mice, keyboards, trackpads, remotes, game controllers,
cables, drives and displays. Meso shows their state, lets you set them up, and links what they can do.

**Download:** grab the latest `Meso-<version>.dmg` from [Releases](https://github.com/linmi/meso/releases).
Meso updates itself after that (Settings → Updates).

Requires macOS 14 or later.

Website: [meso.ac](https://meso.ac)
